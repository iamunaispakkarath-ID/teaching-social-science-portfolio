# Teaching and Social Science Portfolio — Unais P.

A GitHub Pages-ready portfolio repository for school teaching and Social Science education roles.

## What this portfolio shows
- **Classroom teaching and reflection:** a teaching study report from the Class 7 Social Science practicum at Government High School, Kathirkamam, Puducherry.
- **Student-facing curriculum design:** a sample Grade 3 Social Science chapter design and the Understanding Markets workbook.
- **Unit planning:** plans for Understanding Markets and a unit on the Indian Constitution.
- **Teacher development:** a collaboratively developed workshop module on using exit slips as a formative assessment tool.

## Important context
- The Grade 3 chapter PDF contains sample illustrated spreads for selected sections; it is not represented as a complete published textbook.
- The teacher-development module was collaborative work.
- The teaching study report reflects a specific practicum context and should be read as a reflective account, not a claim of long-term measured impact.
- The uploaded BARE reading-ecosystem planning workbook is not duplicated here; it may remain in the curriculum / school-improvement portfolio.
- Student-created work, including the Hajj magazine, is not included in this public repository because attribution and publication permission should be confirmed first.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `teaching-social-science-portfolio`).
2. Upload the contents of this folder to the repository root — `index.html`, `style.css`, `README.md`, and `evidence/`.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Once GitHub publishes the site, copy its Pages URL into the CV.

The site is a static portfolio page. GitHub Pages must be enabled in your account; this ZIP does not create or publish a repository automatically.
